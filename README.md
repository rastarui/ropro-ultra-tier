## How to Install

1. Click the green **Code** button at the top of this GitHub page and select **Download ZIP**.
2. Extract the downloaded `free-ropro-ultra-main.zip` file into your downloads folder.
3. Open any chromium browser and navigate to `chrome://extensions/`.
4. Make sure **Developer mode** toggle is turned on in the top-right corner.
5. Click **Load unpacked** in the top-left corner.
6. Select the extracted folder (**free-ropro-ultra-main**) and verify it registers as a new extension.
7. Refresh Roblox and enjoy free ultra.
